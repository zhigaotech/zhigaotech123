## How to Use

1. **Open in Browser**: Simply open `index.html` in any modern browser
2. **Local Server**: For better experience, run a local server:
   ```bash
   # Python 3
   python -m http.server 8000
   
   # Python 2
   python -m SimpleHTTPServer 8000
   
   # Node.js (if installed)
   npx http-server
   ```
   Then visit http://localhost:8000

3. **Deployment**: Copy all files to your web hosting server
4. **Domain**: Update domain references from www.zhigaotech.com to your actual domain

## Customization

### Colors
Update primary colors in `css/style.css`:
```css
--primary-color: #1f7fb8;
--primary-dark: #0d47a1;
```

### Company Info
Edit company information in HTML files:
- Email addresses
- Physical address
- Website URL
- Contact details

### Content
Replace placeholder team members, services, and features with actual content

### Images/SVG
Customize SVG graphics in:
- `svg/logo.svg` - Company logo
- `svg/favicon.svg` - Browser favicon
- Add more SVG icons in `svg/` folder as needed
